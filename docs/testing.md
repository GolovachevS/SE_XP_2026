# План тестирования

## Цель

Цель тестирования — проверить, что консольный peer-to-peer чат корректно работает на трёх уровнях:

- доменная логика;
- orchestration-слой приложения;
- интеграция транспорта и консольного UI.

## Область покрытия

В автоматическое тестирование входят:

- разбор CLI-аргументов и выбор режима запуска;
- валидация, нормализация и форматирование сообщений;
- поведение консольного ввода-вывода;
- жизненный цикл chat-session в `app`;
- обработка ошибок и закрытия gRPC session;
- обмен сообщениями через in-memory integration tests.

Пока не покрываются автоматическими тестами и проверяются вручную:

- обработка реальных сигналов терминала на разных ОС;
- запуск через Docker;
- выполнение CI pipeline как отдельного сценария.

## Стратегия тестирования

### Unit-тесты

Unit-тесты покрывают изолированную логику и поведение отдельных компонентов:

- `internal/chat`
- `internal/app`
- `internal/ui/console`
- `internal/protocol/chatv1`
- `internal/transport/grpcchat/session.go`

### Интеграционные тесты

Интеграционные тесты проверяют взаимодействие компонентов без реальной сети:

- gRPC transport через `bufconn`;
- двусторонний обмен сообщениями между клиентской и серверной сессией.

### Ручная проверка

Ручные проверки используются для end-to-end сценария в двух терминалах:

1. Запустить сервер без `-peer`.
2. Запустить клиента с `-peer`.
3. Отправить сообщения в обе стороны.
4. Проверить формат отображения сообщений.
5. Проверить поведение при EOF и разрыве соединения.

## Запуск тестов и покрытия

- Все тесты: `go test ./...`
- Через Makefile: `make test`
- Покрытие: `make cover`

Команда `make cover`:

- запускает тесты с `coverprofile`;
- создаёт файлы `coverage.out` и `coverage.html`;
- открывает HTML-отчёт с покрытием.

## Текущее покрытие

Текущая статистика получена командой `go test ./... -coverprofile=coverage.out && go tool cover -func=coverage.out`.

- `internal/app` — `81.5%`
- `internal/chat` — `92.9%`
- `internal/protocol/chatv1` — `100.0%`
- `internal/transport/grpcchat` — `37.5%`
- `internal/ui/console` — `90.0%`
